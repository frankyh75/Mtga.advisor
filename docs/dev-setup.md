# Development Setup (Intent)

This project is currently a private repository and is intended to remain private during early development.

## Target Platforms
- macOS and Windows are primary development and usage targets.
- Linux support is optional and can be evaluated later.

## Collection Export Approach
- Use log-based MTG Arena collection export (local-only).
- Avoid reliance on external services or hosted APIs for core workflows.

## LLM Policy
- Core features must work without any LLM.
- LLM usage is optional and limited to enhancements (e.g., summaries).

## Principles
- Deterministic > magic
- Transparent rules and explainable outputs
- Offline-first where practical
